# DongYeon Kim — Personal Website

A small static website for GitHub Pages. No installation or build step is required.

## Publish
1. Create a public repository named `Kevinkdy.github.io` on your GitHub account.
2. Upload `index.html`, `styles.css`, `cv.pdf`, and `.nojekyll` to its root. Upload the files inside this folder, not the folder itself.
3. Open Settings → Pages.
4. Set Source to Deploy from a branch, Branch to main, and Folder to /(root), then Save.
5. Wait for the Pages deployment to finish. The intended address is https://kevinkdy.github.io/.

## Update
- Edit `index.html` to change the text.
- Edit `styles.css` to change the appearance.
- Replace `cv.pdf` to update your CV, keeping the same filename.
- Commit the changes; GitHub Pages republishes them.

The site is a draft prepared from the CV. Review all text before publishing.
